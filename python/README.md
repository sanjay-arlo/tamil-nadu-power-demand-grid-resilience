# Optional Python Layer

Baseline workflow: **Excel → SQL → Power BI → Decision**.

Use Pandas + NumPy for EDA, peak-event profiling, anomaly detection, repeatable transformations or automation when it adds value.

Suggested use here:
- Pandas: regional demand/capacity profiling and exception analysis.
- NumPy: headroom distributions, percentile thresholds and sensitivity checks.

Python is an optional accelerator; SQL and Power BI remain the governed analytical layers.
